# 📚 نظام إدارة المكتبة والمخزون (C++) | Library & Inventory Management System

مشروع تطبيقي مكتوب بلغة **++C** يعتمد على البرمجة الكائنية (**OOP**)، تم إنشاؤه وتطويره كجزء من **خارطة التعلم والتدريب العملي** على مفاهيم البرمجة الكائنية وتصميم الأنظمة عبر واجهة السطر البرمجي (Console Application).

---

## 🎯 هدف المشروع

تم تطوير هذا المشروع للتدرب والتطبيق العملي على:
* **مفاهيم البرمجة الكائنية (OOP)**: التغليف (Encapsulation)، الوراثة (Inheritance)، وتعدد الأشكال (Polymorphism).
* **تطبيق عمليات CRUD الأساسية**: الإضافة (Create)، القراءة (Read)، التعديل (Update)، والحذف (Delete).
* **تصميم الأنظمة بطبقات مستقلة (Layered Architecture)**: فصل منطق العمل والكلاسات عن واجهات العرض والتفاعل مع المستخدم.

---

## 🌟 المميزات الأساسية

### 🔐 1. إدارة المستخدمين والصلاحيات (User Management)
* **نظام تسجيل الدخول**: التحقق من هوية المستخدم وكلمة المرور.
* **نظام الصلاحيات**: تحديد مستويات الوصول للمشرفين والمستخدمين.
* **عمليات CRUD للمستخدمين**:
  * 📋 عرض قائمة المستخدمين (Show User List)
  * ➕ إضافة مستخدم جديد (Add New User)
  * ✏️ تعديل بيانات مستخدم (Update User Info)
  * ❌ حذف مستخدم (Delete User)
  * 🔍 البحث عن مستخدم (Find User)

---

### 📦 2. إدارة المخزون والمنتجات (Inventory Management)
* **إدارة المنتجات والكتب**: إمكانية الإضافة والتعديل والحذف للأصناف.
* **متابعة الكميات والأسعار**: تتبع أسعار المواد، الكميات المتاحة، والنسب الضريبية.
* **سندات التحويل**: متابعة حركة الأذونات وسندات التحويل بين الأقسام.

---

### 📖 3. إدارة المؤلفين والكتب (Author & Book Cataloging)
* **سجل المؤلفين**: إضافة وتعديل والبحث عن بيانات المؤلفين.
* **سجل الكتب**: متابعة تفاصيل الكتب والطلبات المعلقة.

---

### 💳 4. المبيعات والعمليات المالية (Sales & Transactions)
* **شاشة البيع (POS)**: إصدار الفواتير وإتمام عمليات البيع.
* **الطلبات المعلقة**: متابعة وتجهيز طلبات العملاء المعلقة.
* **سجل المعاملات**: تتبع العمليات المالية وسجلات البيع.

---

## 🛠️ البنية البرمجية والتقنيات المستخدمة

* **اللغة**: ++C (Object-Oriented Programming).
* **الهيكلية البرمجية**:
  * **كلاسات البيانات والمنطق (Core Models)**: مثل `clsPerson`, `clsUser`, `clsClient`, `clsAuthor`, `clsBook`, `clsInvoice`, `clsItem`.
  * **كلاسات الواجهات (UI Screens)**: كلاسات مستقلة لإدارة الشاشات والتفاعل مع المستخدم (مثل `clsAddNewUserScreen`, `clsUpdateUserScreen`, `clsLoginScreen`).
* **حفظ البيانات (Data Persistence)**: التخزين باستخدام الملفات النصية (`Users.txt`, `Items.txt`, `Authers.txt`, إلخ) لتأمين استمرارية البيانات.

---

## 🚀 كيفية التشغيل

1. **المتطلبات**: بيئة Visual Studio (مع حزمة C++ Desktop Development) أو أي محرر يدعم ++C.
